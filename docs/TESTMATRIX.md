# Testmatrix

## Automatisiert

| Bereich | Prüfung |
|---|---|
| Plugin-Metadaten | XML-Struktur, ID, Version, Mindestversion, Urheber |
| EU-Dateien | Existenz und SHA-256 gegen Manifest |
| GARAN | Aktivierung, Laufzeit, Marke, Modell und HTTPS-Link |
| Artikeldaten | direkte und verschachtelte Wawi-Funktionsattribute |
| Sprachen | Deutsch, Englisch und kontrollierter Fallback |
| HTML | Maskierung, sichtbare EU-Grafik, Dialogattribute, beide GARAN-Grafiken |
| Paket | Plugin-Wurzelordner, Pflichtdateien, keine Entwicklungsdaten |

## Manuelle Abnahme vor Produktion

Auf einer gesicherten Testinstanz mit JTL-Shop 5.5 und der aktuell eingesetzten 5.x-Version sind Installation, NOVA/ChildTheme, Produktseite, Warenkorb, Bestellschritt, OPC, Sprachen, Tastaturbedienung und 390/768/1280/1440 Pixel zu prüfen.

Eine Live-Schaltung erfolgt erst nach dieser Prüfung und einer individuellen rechtlichen Freigabe.
