# Sicherheitsrichtlinie

## Sicherheitsprobleme melden

Bitte veröffentlichen Sie Sicherheitslücken nicht zuerst als öffentliches Issue. Melden Sie sie vertraulich über die auf [Michael-Gahn.de](https://Michael-Gahn.de) angegebene Kontaktmöglichkeit. Beschreiben Sie betroffene Version, Reproduktionsschritte und mögliche Auswirkungen, aber senden Sie keine echten Kunden- oder Zugangsdaten.

## Schutzumfang

Das Plugin verarbeitet keine Zahlungsdaten und speichert keine personenbezogenen Daten. Es lehnt unsichere Garantie-URLs ab, maskiert Artikeldaten vor der HTML-Ausgabe und lädt die offiziellen EU-Grafiken lokal. Für das Plugin werden keine externen Laufzeitdienste oder Geheimnisse benötigt.
