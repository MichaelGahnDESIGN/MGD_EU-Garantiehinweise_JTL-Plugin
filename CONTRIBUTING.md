# Mitwirken

Vielen Dank für das Interesse an diesem Plugin. Änderungen sollen klein, nachvollziehbar und mit JTL-Shop 5.5 sowie der aktuellen 5.x-Version vereinbar bleiben.

1. Einen eigenen Branch anlegen.
2. Änderungen verständlich auf Deutsch kommentieren und dokumentieren.
3. `php tests/run.php` sowie die PHP- und XML-Prüfungen aus der README ausführen.
4. Keine Zugangsdaten, Kundendaten, Serverpfade oder proprietären Dateien einreichen.
5. In einem Pull Request Zweck, Testumfang und mögliche Risiken nennen.

Frontend-Ausgaben müssen ohne Tracking funktionieren, Nutzereingaben maskieren und mit Tastatur sowie Screenreader bedienbar bleiben.
